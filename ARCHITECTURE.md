# 音樂播放器架構說明 (Music Player Architecture)

## 系統架構圖

```
┌─────────────────────────────────────────────────────────────────┐
│                      音樂播放器 (MusicPlayer)                     │
│                         QMainWindow                              │
└─────────────────────────────────────────────────────────────────┘
                              │
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
        ▼                     ▼                     ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 播放引擎     │     │  用戶界面    │     │  資料管理    │
│ (Core)       │     │  (UI)        │     │  (Data)      │
└──────────────┘     └──────────────┘     └──────────────┘
```
