# Music Player - 音樂播放器

這是一個功能完整的音樂播放器應用程式，使用 Python 和 PyQt5 開發。

## 功能特點

### 1. 播放清單管理
- 使用 QMediaPlaylist 管理多首歌曲
- 支援添加、刪除歌曲
- 可以上下調整歌曲播放順序
- 支援多個播放清單的建立和切換
- 可以保存和載入播放清單（JSON 格式）

### 2. 播放控制
- **上一首/下一首**: 快速切換歌曲
- **播放/暫停/停止**: 完整的播放控制
- 雙擊播放清單中的歌曲直接播放

### 3. 播放進度顯示
- 使用 QSlider 顯示和控制播放進度
- 即時顯示當前播放時間和總時長（mm:ss 格式）
- 可以拖動進度條跳轉到指定位置

### 4. 歌曲封面展示
- 使用 mutagen 庫讀取 MP3/FLAC 等格式的嵌入封面
- 封面顯示在播放器界面中
- 切換歌曲時自動更新封面

### 5. 播放器控制界面
- 簡潔直觀的用戶界面
- 音量控制滑桿（0-100%）
- 所有常見播放器控制按鈕

### 6. 多格式支援
支援多種音頻格式：
- MP3
- WAV
- FLAC
- AAC
- M4A
- OGG

### 7. 字幕顯示功能
- 支援 LRC 格式的字幕檔案
- 字幕隨音樂播放自動高亮顯示
- 點擊字幕行可以跳轉到對應時間位置
- 自動載入與歌曲同名的 .lrc 字幕檔案
- 支援手動載入字幕檔案

## 安裝說明

### 系統需求
- Python 3.6 或更高版本
- PyQt5
- mutagen

### 安裝步驟

1. 克隆此倉庫：
```bash
git clone https://github.com/Weizhe422/Music.git
cd Music
```

2. 安裝依賴：
```bash
pip install -r requirements.txt
```

## 使用方法

### 啟動播放器
```bash
python music_player.py
```

### 基本操作

#### 添加歌曲
1. 點擊「➕ 添加歌曲」按鈕
2. 或使用選單：檔案 → 添加音樂檔案
3. 選擇一個或多個音頻檔案

#### 播放控制
- **播放**: 點擊「▶ 播放」按鈕
- **暫停**: 點擊「⏸ 暫停」按鈕
- **停止**: 點擊「⏹ 停止」按鈕
- **上一首**: 點擊「⏮ 上一首」按鈕
- **下一首**: 點擊「⏭ 下一首」按鈕
- **雙擊播放清單中的歌曲**: 直接播放該歌曲

#### 調整播放順序
1. 選擇播放清單中的歌曲
2. 點擊「⬆ 上移」或「⬇ 下移」按鈕調整順序

#### 音量控制
- 拖動音量滑桿調整音量（0-100%）

#### 進度控制
- 拖動進度滑桿跳轉到指定播放位置

#### 載入字幕
1. 點擊「📝 載入字幕」按鈕
2. 選擇 .lrc 字幕檔案
3. 字幕將自動同步顯示
4. 點擊任意字幕行跳轉到對應時間

**注意**: 如果歌曲檔案與 .lrc 字幕檔案同名（例如：song.mp3 和 song.lrc），字幕將自動載入。

#### 播放清單管理
- **新建播放清單**: 選單 → 播放清單 → 新建播放清單
- **切換播放清單**: 選單 → 播放清單 → 切換播放清單
- **保存播放清單**: 選單 → 播放清單 → 保存播放清單（保存為 JSON 檔案）
- **載入播放清單**: 選單 → 播放清單 → 載入播放清單（從 JSON 檔案載入）

## LRC 字幕格式說明

LRC 檔案格式範例：
```
[00:00.00]這是第一句歌詞
[00:05.50]這是第二句歌詞
[00:10.20]這是第三句歌詞
```

格式說明：
- `[mm:ss.xx]` 表示時間標記（分:秒.毫秒）
- 時間標記後接歌詞文字
- 每行一句歌詞

## 技術實現

### 核心技術
- **PyQt5**: 用戶界面框架
  - QMediaPlayer: 媒體播放
  - QMediaPlaylist: 播放清單管理
  - QSlider: 進度和音量控制
  - QListWidget: 播放清單和字幕顯示
  - QLabel: 封面和資訊顯示
- **mutagen**: 音頻元數據讀取和封面提取

### 主要功能實現

1. **播放清單管理**: 使用 QMediaPlaylist 結合 Python 列表進行同步管理
2. **封面提取**: 使用 mutagen 讀取音頻檔案的嵌入圖片
3. **字幕同步**: 解析 LRC 格式，使用 positionChanged 信號實時更新高亮
4. **進度控制**: 雙向綁定 QSlider 和 QMediaPlayer 的播放位置
5. **多播放清單**: 使用字典存儲多個播放清單，支援 JSON 序列化
